# 研究报告写作结构

## 结论先行

读者通常只先看标题和摘要。报告开头应直接给出核心判断，而不是从背景慢慢铺陈。推荐结构：标题 → 一句话结论 → 摘要 → 关键发现 → 分析 → 风险 → 下一步行动。

## 事实、推断、建议要分开

- **事实**：有来源、可核验的信息；
- **推断**：基于事实的分析，应说明假设；
- **建议**：面向行动的选择，应说明代价和适用条件。

把三者混在一起，会让读者误以为推断是事实。研究 Agent 的中间产物应该显式标注不确定性。

## 表格适合做对比

当需要比较多个方案、竞品或维度时，表格比长段落更易读。列不要太多，最好控制在 4-5 列；每格只放一个判断，不要把整段话塞进表格。

## 行动项要具体

“加强关注”“持续优化”不是行动项。好的行动项包含：做什么、谁来做、什么时候、如何判断完成。例如“本周用 20 条真实问题对比 qwen2.5:7b 与 gpt-4o-mini 的结构完整率”。

## 常见问题

1. 标题很大，内容很空；
2. 通篇都是“首先、其次、最后”，没有真正的论点；
3. 数据没有时间、口径和来源；
4. 只写优点，不写风险和反例；
5. 建议不可执行，或者与前面的分析无关。

## 自动生成后的检查清单

- 摘要是否能在 100 字内说清结论？
- 每个数字是否有来源？
- 是否区分了事实与推断？
- 是否有反例或边界条件？
- 下一步行动是否具体、可验证？
- 是否删除了重复和空话？
